## Overview

The Dashboard is a sleek and modern dashboard built with Shadcn. It features a responsive design with support for both light and dark modes.

## Getting Started

### Installation

To begin, install the required dependencies using the following command:

```bash
pnpm i
```

# Development Server

After installing the dependencies run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:4000) with your browser to see the result or https://vkkumar2002.github.io/Dashboard/.
